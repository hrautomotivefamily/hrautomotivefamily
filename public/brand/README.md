# Brand logo

To use your real logo, upload these two files into this folder
(`public/brand/`) via GitHub → **Add file → Upload files**:

```
public/brand/
  logo.png        ← full-colour logo (navy/charcoal) for light backgrounds
  logo-white.png  ← white/knockout logo for the dark navy header & footer
```

As soon as they're present, the site automatically shows your logo in the
header and footer **in place of the "HR Automotive" text**. Until then, it falls
back to the built-in car mark + name, so the site always looks complete.

- PNG with a transparent background works best (SVG also fine — just name them
  `logo.png` / `logo-white.png` anyway, or tell me and I'll switch the paths).
- No code changes needed — just upload the files.
